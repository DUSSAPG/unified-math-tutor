# Store Readiness Checklist

Use this checklist before preparing Play Store or App Store release submissions.

## Required Assets and Pages

- [ ] App icon
- [ ] Splash screen
- [ ] Privacy policy
- [ ] Terms
- [ ] Help/contact
- [ ] Store screenshots

## Store Identity

- [ ] Android package ID selected
- [ ] iOS bundle ID selected

## Services

- [ ] RevenueCat products defined
- [ ] Firebase project created

## Validation

- [ ] Release build test completed
- [ ] Locale test completed: `en_GB`
- [ ] Locale test completed: `de_CH`
- [ ] Locale test completed: `fr_CH`
- [ ] Locale test completed: `it_CH`
- [ ] Locale test completed: `ko_KR`
