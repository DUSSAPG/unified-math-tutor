## ⚠ Evidence-level disclaimer (applies to every claim in this document)

Every age/stage, domain, and pedagogical-pattern claim in this document was derived **only** from a file's filename, title, author/publisher name, series name, or publicly known facts about that series (e.g. that "GCSE Edexcel grade 9-1" is a UK exam-board spec name, or that "Singapore Math" refers to a publicly documented method). No PDF was opened. Accordingly, every row and every claim below carries:

- **evidenceLevel: `bibliographic_inference_only`**
- **confidence: `low` / `unverified`**
- **This is not evidence of the actual book's structure, pedagogy, or curriculum coverage.** A title suggesting "Higher tier" content, a "revision guide" format, or a specific age band is a guess consistent with how such titles are conventionally used in publishing — it is not a verified description of what is actually printed inside that specific file.
- **This is not, and must never be treated as, a basis for any learner-facing availability or content decision in Math Intelligence.** Whether a topic is available to a learner is decided *exclusively* by the curriculum manifest (`assets/config/curriculum_manifest.json`) and its resolver invariants — never by anything in this document.

Nothing in the table below should be read as "book X contains Y" as fact. It should be read as "the filename/title/series of book X is consistent with Y, unverified."

## Copyright-safety methodology (read this before the table)

This map was built **without opening any PDF's content**. No page was read, no text was extracted, no OCR was run, and no table of contents, diagram, question, answer key, or exercise was inspected. The only tools available in this environment for this pass were filename inspection and general, publicly-known facts about each named series, publisher, exam board, or curriculum code. Every "apparent," "likely," "presumed," and "guessed from title" in this document reflects that constraint — it is bibliographic-level inference, not a content audit, and is not upgraded to fact anywhere below.

If a future pass genuinely needs verified structural facts (page count, unit count, table-of-contents headings), that should come from a metadata-only tool (e.g. a page-count/outline reader) that still never extracts body text, diagrams, or exercises — and any such finding should update the **evidenceLevel** for that row specifically (e.g. to `metadata_verified`), not silently raise confidence on the inference columns already here.

**Hard rule carried into every later document in this set:** a topic appearing in a reference book's apparent scope is never treated as evidence that Math Intelligence has, or should silently claim, matching content. Availability in the app is decided only by the curriculum manifest, never by what a reference book's title happens to suggest.
