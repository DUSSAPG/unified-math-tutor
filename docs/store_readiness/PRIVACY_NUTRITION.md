# Privacy Nutrition Draft

## Data Collected

- No account is required for local practice.
- Practice history, parent-tool preference, and the parent PIN hash are stored locally.
- Parent PDF reports are generated locally and shared only when the user chooses an export destination.

## Data Not Collected By This Build

- No advertising identifiers.
- No precise location.
- No contacts, photos, or health data.
- No plaintext parent PIN.

## Store Review Checks

- Confirm any future analytics SDK before submission.
- Confirm any future account or cloud-sync feature before submission.
- Update the store privacy form if Tutor networking is enabled in a production flavor.
